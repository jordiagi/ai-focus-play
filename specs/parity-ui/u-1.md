# U-1 — Hash routing and a Share link that actually shares

## Problem
Veo's match page is hash-routed: base (video), plus `#/analysis/`, `#/player-moments/`,
`#/highlights/`, `#/events/`, `#/lineup/`, `#/summary/`. Our clone has **no router at
all** — panel choice is `useState` in `App.tsx`, so no panel is linkable and the browser
back button does nothing.

Consequently `Header.tsx:22-26` "Share" copies `window.location.href`, which is
**identical for every match and every panel**. It is a share button that shares nothing.

## Files OWNED (edit only these)
- `frontend/src/App.tsx`
- `frontend/src/components/Header.tsx`

## Files READ (do not edit)
`frontend/src/components/Sidebar/SidebarTabs.tsx`, `RightToolbar.tsx`,
`frontend/src/services/api.ts`, `frontend/src/types/index.ts`

## Contract
- Implement hash routing with **no new dependency** — Veo's scheme is hash-based and a
  `hashchange` listener plus `location.hash` is ~30 lines. Do not add react-router.
- Map exactly onto Veo's routes. Our existing drawer keys map 1:1:
  `analytics→#/analysis/`, `players→#/player-moments/`, `highlights→#/highlights/`,
  `events→#/events/`, `lineup→#/lineup/`, `summary→#/summary/`, none→base.
- Opening a URL with a hash must **restore that panel on load**, not just on click.
- Browser back/forward must move between panels.
- An unknown hash falls back to the base route without throwing.
- Share copies the **current** URL including the active panel hash. If a match id is
  representable in the URL, include it; if you cannot do that without touching files you
  do not own, say so in `deviations` rather than faking it.
- Do not regress the existing keyboard shortcuts or the drawer close button.

## Acceptance (run it, paste real output)
```
cd frontend && npm run build && npm run lint
```
Build must succeed; lint must show **no new** warnings (one pre-existing at `App.tsx:86`).

Then, with `bash scripts/local/dev.sh up` or `npm run dev`, verify by script or browser
and paste the evidence:
- loading `/#/events/` directly opens the Events panel
- clicking through panels updates `location.hash`
- back button returns to the previous panel
- Share copies a URL whose hash matches the open panel

## Out of scope
Panel *contents* (U-3 owns `SidebarTabs.tsx`). The jersey bar (U-2). Any backend file.
